# Example usage of the ski_bench framework platform

The ski_bench framework platform is specifically made for `0001-ski-mitigations-off-bench`,
however it has been developed for any A/B style (or later more) benchmarking for bski.

Current examples:
- `0001-ski-mitigations-off-bench`  # Our main real-world example,
                                        # currently still using old c file, WIP migration
- `0002-simple-instance`            # The most simple compiling program using ski_bench
- `0003-simple-empty-bench`         # A very minimal  empty look at using ski_bench

These examples are subject to change at any time for any reason,
and could theoretically use a current unsupported out-dated version of ski_bench.
